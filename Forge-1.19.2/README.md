# Block ID

Minecraft 1.20.1 方块ID管理与 WorldEdit 指令生成客户端模组。

## 功能

- 🎯 方块ID快速复制（多选，逗号分隔）
- ⚡ WorldEdit 指令一键生成（`//set`、`//replace`）
- 🔧 方块状态属性可视化设置（朝向、半层、含水等）
- 📊 放置率权重滑块，自动归一化 100%
- 🔍 智能搜索（中文名 / 英文ID / 拼音首字母）
- ⭐ 常用方块自动收集与管理
- 🌍 9种语言支持

## 版本

当前版本：**2.0.3.1-Release**

支持加载器：Forge 47+ / Fabric 0.15+

## 前置模组

- WorldEdit（必需）
- Cloth Config API（必需）

## 使用

- 按 **G** 打开管理界面
- 按 **C** 复制手持方块ID
